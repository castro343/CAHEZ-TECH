# CAHEZ TECHNOLOGIES — Corporate Website

The public corporate website for CAHEZ TECHNOLOGIES.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm run start
```

## Deployment

In Vercel, import the CAHEZ-TECH repository and set the project Root Directory to `apps/corporate-website`. Use the package manager lockfile generated by the selected deployment/build environment. No environment variables are currently required.
